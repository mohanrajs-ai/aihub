# Product Definition: Gemini Enterprise AI Hub Portal (`aihub`)

## 1. Vision & Overview
**`aihub`** is the Single-Portal RBAC Web UI (`frontend/`) and FastAPI Control Plane & Skill Workflow Backend (`backend/`) for Google Cloud Gemini Enterprise (Discovery Engine).

## 2. Core Capabilities
1. **Federated Multi-App Discovery Portal (`frontend/` + `backend/app/`):**
   - Live Discovery Engine & Data Store synchronization with Cloud Identity Group RBAC filtering and OIDC-safe popup launching.
2. **Self-Service Provisioning & Skill Governance Studio UI (`frontend/` + `backend/`):**
   - Admin web interface for monitoring customer provisioning jobs, reviewing 6-stage skill governance runs, and managing pinned assistant agents.
